# Сайт-поздравление для Юли

Страницы идут по порядку, везде кнопка «Далее»:

1. `index.html` — появляется главное фото
2. `congrats.html` — всплывают фото и играет голос ребёнка
3. `joke.html` — «подарок» с шуточным вариантом и смеющимися смайликами
4. `memory.html` — «Ой, я вспомнила…» и «19 лет» под спойлером, как в Телеграме
5. `gift.html` — настоящий подарок
6. `certificate.html` — кнопка «Скачать сертификат»

## Что положить в папки

| Файл | Что это |
|---|---|
| `assets/photos/main.jpg` | главное фото на первой странице |
| `assets/photos/1.jpg … 6.jpg` | фото, которые всплывают на второй странице |
| `assets/voice.mp3` | запись голоса ребёнка |
| `assets/certificate.pdf` | сертификат для скачивания |

Названия и количество фото, а также ссылки и тексты кнопок меняются в одном месте: `js/config.js`.

## Выложить

GitHub: создать репозиторий, загрузить всё содержимое папки.
Netlify: Add new site → Import from Git → выбрать репозиторий. Build command не нужен, Publish directory — корень.

Проверять сайт локально лучше через простой сервер (`python3 -m http.server`), а не двойным кликом по файлу.

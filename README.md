# Сайт-поздравление для Юли

Все файлы лежат в одной папке, без вложенных папок.

Страницы по порядку: index.html → congrats.html → joke.html → memory.html → gift.html → certificate.html

Что добавить рядом с ними:
- main.jpg — главное фото на первой странице
- 1.jpg ... 6.jpg — фото, которые всплывают на второй странице
- voice.mp3 — запись голоса
- certificate.enc — ЗАШИФРОВАННЫЙ сертификат (см. ниже)

Ссылки, тексты и имена файлов меняются в config.js.

## Сертификат под паролем

Сам PDF на GitHub не загружается. Вместо него на сайте лежит certificate.enc, который без пароля прочитать нельзя.

1. Скачайте папку сайта на компьютер и откройте файл encrypt.html в браузере (двойным щелчком).
2. Выберите PDF, придумайте пароль, нажмите «Зашифровать и скачать».
3. Загрузите полученный certificate.enc на GitHub рядом с остальными файлами.

Файл encrypt.html на GitHub загружать не нужно, он нужен только у вас на компьютере (рядом с vault.js).
Пароль не регистрируется ни в одном файле сайта. Регистр букв не важен.
